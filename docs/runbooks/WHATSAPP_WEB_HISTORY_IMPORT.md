# Runbook — импорт СТАРОЙ истории WhatsApp через WhatsApp Web

**Статус: это ОСНОВНОЙ способ получения старых переписок.** (Ранее рассматривался импорт из
бэкапа Google Drive — `scripts/wa-backup-import.js`, требующий расшифровки `msgstore.db` ключом
E2E. От него отказались в пользу WhatsApp Web: не нужен рут телефона и ключ шифрования.)

## Зачем
GOWA/Cloud API пишут в архив `whatsapp_messages` только **новые** сообщения (примерно с 30 июня
2026). Всё, что было раньше, агенту недоступно — а именно там лежат спорные моменты. Этот импорт
подтягивает историю чатов в тот же архив, который читают панель (`/api/control-center/wa-search`),
досье клиента (`taskInboxService.thread` — последние 10 сообщений) и аналитика.

## Как это работает
`backend/scripts/wa-web-history-import.js` линкуется к аккаунту как **отдельное устройство**
(«Связанные устройства» → скан QR), проходит по чатам, тянет историю (`chat.fetchMessages`) и
складывает в Mongo с дедупом по `provider_message_id`, помечая `provider: 'import'`.

**Безопасно:**
- **Read-only для WhatsApp** — только читает историю, ничего не отправляет и **не помечает
  прочитанным** (инвариант unread не нарушается).
- **Multi-device** — это отдельная линкованная сессия (`clientId: 'history-import'`), поэтому
  боевой канал GOWA **не отваливается** (WhatsApp допускает до 4 устройств).
- **Идемпотентно** — дедуп по `provider_message_id`, можно гонять повторно (докачивает новое).

## Предусловие (делает оператор)
Номер, чью историю тянем, должен быть **залогинен в приложении WhatsApp** на телефоне и иметь
доступ к **Настройки → Связанные устройства** (чтобы отсканировать QR). Скан QR — единственный
ручной шаг, его выполняет оператор со своего телефона.

## Зависимости
Тяжёлые опциональные пакеты (тянут puppeteer/Chromium), намеренно **не** в `package.json`, чтобы
не раздувать прод/API-образ. Они **вшиты только в образ `wa-web`** (`deploy/Dockerfile.whatsapp`:
`npm i --no-save whatsapp-web.js@1.34.7 qrcode-terminal@0.12.0`, там же distro Chromium). Поэтому
на VPS ничего доустанавливать не нужно — только пересобрать образ (см. ниже).

## Запуск — ОСНОВНОЙ путь: на VPS (пишет в прод-Mongo)
Основная программа и архив (`whatsapp_messages`, который читает панель) живут на VPS, а прод-Mongo
наружу не выставлен. Поэтому импорт гоняем **на VPS**, внутри образа `wa-web` — в нём есть Chromium,
сеть до Mongo (`MONGODB_URI` уже задан в сервисе) и папка `scripts/`.

```
ssh -i ~/.ssh/cw_deploy root@157.180.38.103
cd /opt/certification-workflow

# 1) один раз пересобрать образ wa-web (чтобы подхватил вшитые deps)
docker compose --profile waweb build wa-web

# 2) сухой прогон — покажет объём, в базу не пишет
docker compose --profile waweb run --rm wa-web \
  node scripts/wa-web-history-import.js --since=2026-01-01 --dry

# 3) боевой прогон — отсканируй ASCII-QR прямо из вывода SSH-терминала
docker compose --profile waweb run --rm wa-web \
  node scripts/wa-web-history-import.js --since=2026-01-01
```
Скан QR (WhatsApp → Связанные устройства) — единственный ручной шаг.

### Флаги
- `--since=YYYY-MM-DD` — импортировать только сообщения новее даты.
- `--limit=500` — сколько последних сообщений тянуть на чат (по умолчанию 500).
- `--chat=996555` — только чаты, где id/имя содержит подстроку (напр. номер клиента).
- `--dry` — показать, что было бы импортировано, ничего не писать.
- `--me=<мой номер>` — помогает корректно проставить from/to (иначе берётся из `fromMe`).

## Запуск локально (только для теста, если есть локальный Mongo)
```
cd backend
npm i whatsapp-web.js qrcode-terminal        # разово, если ещё не стоят
npm run wa:history -- --since=2026-01-01 --dry
npm run wa:history -- --since=2026-01-01
```

## После импорта
- Проверь, что архив вырос: поиск в панели по клиенту (`/api/control-center/wa-search?phone=…`).
- Историческое НЕ засоряет инбокс задач: у импортированных сообщений старый `received_at`, поэтому
  они идут в поиск/досье, но не всплывают как свежие задачи.
- Точность определения «оплатил/отказался» по старым перепискам (`taskInboxService.isRefused` /
  `clientSaidPaid`) после импорта повышается — раньше WhatsApp-архив был только с ~30 июня.
